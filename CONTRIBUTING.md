# Contributing

Thank you for helping improve EduPilot.

1. Open an issue for substantial behavior or data-model changes.
2. Keep the default experience local-only and usable without an account or paid hosted service.
3. Never commit PDFs, SQLite databases, `.env` files, access tokens, service-account files, or generated study content.
4. Add backend tests for API/data changes and run both frontend checks before opening a pull request.
5. Keep API errors actionable and avoid sending document contents anywhere except the user-configured Ollama endpoint.

By contributing, you agree that your contribution is licensed under the MIT License.
